# Cycle Scholar

Build an Educational Period Tracker App for Students

Create a modern, elegant, and educational mobile application focused on helping students understand the menstrual cycle while also tracking their periods. The app should prioritize learning, health awareness, and simplicity rather than only prediction.

Design Language

- Primary Colors: Black (#0D0D0D), Royal Blue (#2563EB), Gold (#D4AF37)

- Avoid: Pink, purple, or stereotypical feminine themes.

- Use a clean, premium, minimal interface inspired by modern educational apps.

- Rounded cards, smooth animations, glassmorphism where appropriate, and dark mode by default.

- The design should feel scientific, trustworthy, and inclusive.

Main Goal

Help students answer:

- What is happening in my body today?

- Why do I feel this way?

- What should I do today?

- What will happen next in my cycle?

Core Features

1. Smart Period Tracker

- Track period start and end dates.

- Predict future periods using adaptive learning.

- Display current cycle day.

- Show cycle history.

2. Interactive Cycle Journey

Instead of only showing a calendar, display the menstrual cycle as a journey with four phases:

- 🩸 Menstrual Phase

- 🌱 Follicular Phase

- 🌼 Ovulation Phase

- 🌙 Luteal Phase

Each phase should include:

- What is happening inside the uterus and ovaries.

- Hormone changes (Estrogen and Progesterone).

- Expected emotions.

- Expected energy level.

- Common symptoms.

- Self-care tips.

- Nutrition suggestions.

- Exercise recommendations.

- Fun scientific facts.

3. Today's Learning Screen  no repeated questions or info

Every day the user opens the app, show:

- Today's cycle phase.

- Body changes happening today.

- Hormones active today.

- One educational lesson (2–3 minute read).

- A "Did You Know?" fact.

- A daily health tip.

5. Learn Section no repeated questions or info

A structured library with beginner-friendly topics:

- What is a menstrual cycle?

- Why do periods happen?

- Hormones explained.

- Ovulation.

- PMS.

- Blood colors and what they may mean.

- Common myths vs facts.

- Period hygiene.

- Nutrition during each phase.

- Exercise during each phase.

- When to seek medical advice.

8. Calendar & Timeline

Display:

- Past periods

- Predicted periods

- Ovulation

- Fertile window (optional)

- Current phase

9. Progress Dashboard

Show:

- Current cycle phase

- Days until next period

- Cycle regularity

- Symptom trends

- Learning streak

- Lessons completed

Clearly state that the app provides educational information and does not diagnose medical conditions.

User Experience

- Fast onboarding.

- Friendly language suitable for teenagers and college students.

- Beautiful illustrations of the reproductive system and cycle phases.

- Smooth animations between cycle phases.

- Offline support for learning content.

- Secure local storage with optional cloud backup.

- Privacy lock using PIN or biometrics.

Overall Feel

The app should feel like a combination of a premium health tracker, an interactive biology textbook, and a personal learning companion. Every screen should teach users something new about their menstrual health while making tracking simple, engaging, and visually appealing.
